# MesaClick

## Descripción del Problema

MesaClick es una aplicación web diseñada para facilitar la gestión de pedidos en restaurantes. Permite organizar la atención de las mesas, optimizar el servicio al cliente y mejorar el control de los pedidos mediante una interfaz sencilla e intuitiva.

## Tecnologías Utilizadas

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Node.js
- NPM
- Git
- GitHub
